About

        
How this works, and what it is built on.

      


      
✓
Everything runs locally on this machine. No account, no cloud service, no telemetry. Lyrics are fetched from public endpoints using the track title and artist only.


      

        
⇄Pipeline

        

          

            
Windows SMTC → smtc-bridge → this app → OBS browser source

            
Playback state and metadata are read from Windows through smtc-bridge's REST API, matched against four lyric providers, and pushed to the overlay over a local WebSocket.

          

        

      


      

        
★Built on

        

          
smtc-bridge
Exposes Windows media sessions as a REST API. Supplies title, artist, album, artwork and timeline.

            
Source

          
tosu-lyrics
Reference for the overlay's three-line carousel look and lyric timing model.

            
Source

          
AF-Media-Bar
Reference for multi-source lyric search, candidate scoring, and this control panel's visual style.

            
Source

        

      


      

        
⚖Lyric providers

        

          
LRCLIB
Open, community-maintained, synced LRC. Needs no key and handles CJK titles.

          
NetEase Cloud Music
Strong CJK catalogue, supplies original, translation and romanisation.

          
QQ Music
Very broad CJK coverage; requires a Referer header, which this app sets server-side.

          
Kugou
Used as a further CJK fallback. Searched by title only, then ranked by duration.
